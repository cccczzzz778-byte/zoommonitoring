Buxoro Meeting Monitor Documentation

Purpose

The application helps authorized administrators monitor Zoom meeting attendance and participant status and generate Excel reports.

How to use

  1. Open the monitoring website.
  2. Enter the administrator monitor key.
  3. Enter the Zoom meeting ID and meeting password.
  4. Select Zoom authorization and complete Zoom OAuth authorization.
  5. For an external-account meeting, make sure the authorized Zoom user is already present in that meeting if required by Zoom's OBF workflow.
  6. Select Start monitoring.
  7. Review live attendance, camera status, camera-off duration, Phone/PSTN status, and participant join/leave events.
  8. Select Excel report to export the monitoring session. An authorized Telegram administrator may also request the latest report through the configured bot.

Zoom data used

The application uses OAuth authorization and the Zoom Meeting SDK. It requests the minimum Zoom permissions needed for the configured workflow, including user:read:token for obtaining an OBF token when required.

Data not collected

The application does not intentionally record meeting audio, meeting video streams, screen-sharing content, or private chat messages.

Troubleshooting

If Zoom shows an external meeting error, verify that the production app is approved for the required Meeting SDK use case and that the correct authorized user is present in the target meeting. If authorization expires, authorize Zoom again from the monitoring page.

Removing access

Users or Zoom account administrators can revoke the application's authorization from Zoom account or Marketplace settings. Revoking authorization prevents the application from obtaining new Zoom access or OBF tokens for that user.

Buxoro Meeting Monitor Documentation

Purpose

The application helps authorized administrators monitor Zoom meeting attendance and participant status and generate Excel reports.

How to add and authorize the app

  1. Open the monitoring website.
  2. Enter the administrator monitor key supplied for the authorized environment.
  3. Select Zoom authorization.
  4. Complete Zoom OAuth authorization and approve the requested scopes.
  5. After authorization, return to the monitoring website.

How to use

  1. Enter the Zoom meeting ID and meeting password.
  2. For an external-account meeting, make sure the authorized Zoom user is already present in that meeting if required by Zoom's OBF workflow.
  3. Select Start monitoring.
  4. Review live attendance, camera status, camera-off duration, Phone/PSTN status, and participant join/leave events.
  5. Select Excel report to export the monitoring session. An authorized Telegram administrator may also request the latest report through the configured bot.

Zoom Marketplace Reviewer Test Plan

Test environment: Web application in a modern desktop browser. No native EXE, APK, or iOS package is required.
  1. Open https://zoommonitoring-production.up.railway.app.
  2. Enter the reviewer monitor key supplied privately in the Marketplace submission notes/credentials.
  3. Click Zoom authorization and sign in with the Zoom test user selected by the reviewer.
  4. Approve the app scopes. The app uses user:read:token to obtain the OBF token required by the configured Meeting SDK workflow.
  5. Start or join a Zoom meeting in the ordinary Zoom client. For an external-account meeting, ensure the authorized Zoom user is present in the meeting before starting monitoring when required by Zoom.
  6. Return to the monitoring site and enter the meeting ID and password.
  7. Click Start monitoring.
  8. Verify that participant join/leave activity appears in the dashboard.
  9. Toggle a participant camera and verify camera ON/OFF state and camera-off duration update.
  10. If a participant joins through PSTN, verify the Phone/PSTN indicator when available from Zoom.
  11. Click Excel report and verify that an XLSX report is generated for the monitoring session.

Zoom data used

The application uses OAuth authorization and the Zoom Meeting SDK. It requests the minimum Zoom permissions needed for the configured workflow, including user:read:token for obtaining an OBF token when required.

Data not collected

The application does not intentionally record meeting audio, meeting video streams, screen-sharing content, or private chat messages.

Troubleshooting

If Zoom shows an external meeting error, verify that the production app is approved for the required Meeting SDK use case and that the correct authorized user is present in the target meeting. If authorization expires, authorize Zoom again from the monitoring page.

Removing the app

  1. Sign in to the Zoom App Marketplace.
  2. Open Manage and then Added Apps.
  3. Select Buxoro Meeting Monitor.
  4. Choose Remove and confirm.

After removal, the user can no longer authorize new Zoom access or OBF tokens through the app. Runtime OAuth and monitoring session data held in application memory is not intended for persistent retention.
